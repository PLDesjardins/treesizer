One-time OneDrive setup
  1. Serve this file locally: in its folder, run python -m http.server 8000 --bind 127.0.0.1, then open http://localhost:8000/index.html.
  2. In Microsoft Entra, open App registrations and register an application. Select accounts in any organizational directory and personal Microsoft accounts.
  3. Add a Single-page application (SPA) redirect URI matching that exact page address. Add Microsoft Graph delegated permission Files.Read.
  4. Copy the Application (client) ID above, then sign in. No client secret is needed. Work accounts may require administrator approval.

The app ID is public. Sign-in tokens stay in memory until you disconnect or close the page. Local folder scanning still works by opening the HTML directly.
